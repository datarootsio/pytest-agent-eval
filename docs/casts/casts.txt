# The cast inventory. One row per asciinema recording embedded in docs/why/.
#
# Format:  slug | title | the docs block it replaces
#
# The title is what `rec.sh` passes to `asciinema rec --title`, so it is what
# asciinema.org shows above the player. Keep it a description of the command, not
# of the page: a reader who lands on the recording out of context should still know
# what they are watching.
#
# Tier A casts are offline and byte-reproducible — a stub agent, a fixed reply list,
# no network. Tier B needs credentials or a long interactive session; those render
# the "Recording pending" placeholder until someone with the credentials records them.
#
# Adding a row is not enough to make a cast real. See CONTRIBUTING.md, "Recording the
# docs/why casts".
